# OpenHarness PRD(产品需求文档)

> 状态:✅ 已确认 v1(2026-08:范围、技术栈均已拍板)
> 上游:[vision-discussion.md](./vision-discussion.md)

## 1. 产品定义

**OpenHarness** 是一个**个人 Agent 控制台**:本地 Web 服务 + 浏览器页面,作为 Cursor、Claude Code、Codex、DeepSeek Harness(后续可扩展更多 Agent 工具)的统一入口,提供任务发射、实时监控、会话管理与深链跳转。它编排和观察**工具本身**,不替代工具、不聚合大模型 API。

### 核心价值主张

| 痛点 | OpenHarness 的解法 |
|---|---|
| 多个 Agent 窗口切换,不知道谁在干什么 | 一个页面实时看到所有 Agent 的活动流 |
| 任务散落在各工具的会话里,难找回 | 统一会话索引:项目 × 工具 × 时间,一键继续 |
| 该用哪个工具全凭记忆 | 发任务时按各工具特色给出智能建议 |
| 想保留各工具原生体验 | 深链一键跳回原工具,原生界面原样保留 |

## 2. 用户与场景

- **用户**:开发者本人(单用户,本地使用)。
- **核心场景**:
  1. 早上打开控制台 → 看到昨天各 Agent 干了什么、哪些任务未完 → 一键恢复;
  2. 接到新任务 → 控制台发任务,页面建议"Claude Code(工程编排)"或"Codex(沙箱实验)" → 人拍板 → 启动;
  3. Agent 运行中 → 控制台实时看消息流与工具调用,随时打断/补发消息;
  4. 想看完整原生界面 → 深链打开 Cursor / 终端里的 Claude Code / Codex。

## 3. 功能需求

### F1 控制台首页(每 Agent 一卡)
- 展示:运行状态(空闲/运行中/已退出)、当前任务摘要、最近会话列表、累计会话数;
- 操作:一键打开该工具最近会话的深链、查看其配置(只读)。

### F2 统一活动流(实时监控)
- 聚合四个工具的事件:会话开始/结束、用户消息、助手消息(节流)、工具调用、文件修改、错误;
- 支持按工具/项目/时间过滤;实时推送(WebSocket/SSE)。

### F3 任务发射(完整控制)
- 表单:任务描述 + 目标项目目录 + 模型偏好(可选);
- **智能建议**:规则评分器按任务关键词 × 工具特色矩阵给出推荐与理由(例:"涉及多步编排与 hook → 建议 Claude Code");
- 执行:spawn 对应工具原生 CLI(`claude -p` / `codex exec` / `cursor agent --print` / `dsh --profile headless`),持有进程句柄;
- 运行中:可发送跟进消息(对支持 stdin 续聊的工具)、可打断(SIGINT)、可查看实时输出。

### F4 会话索引与恢复
- 从各工具本地会话存储建立只读索引(不复制、不迁移数据);
- 会话详情页:标题、项目、时间线摘要、关键消息;
- 恢复:映射到 `claude --resume <id>` / `codex resume <id>` / `cursor agent --resume <chatId>` / `dsh --resume <session>`,在页面或原工具中继续。

### F5 深链跳转
- Cursor:`cursor://` 协议 / `cursor <path>` 打开工作区;
- Claude Code / Codex:在终端中打开并 `--resume` 指定会话;
- DSH:打开 `dsh web` 对应页面 URL。

### F6 用量统计(MVP 可选项,默认含)
- 聚合各工具 token 消耗与调用次数(数据源:Claude 会话 JSONL 的 usage 字段、Codex rollout 的 usage、DSH 会话记录;Cursor 精度有限,标注"估算");
- 展示:今日/本周总量,按工具与项目拆分。

## 4. 范围与优先级

### v0.1 MVP(第一期)
- F1 简化版(状态 + 最近会话 + 深链)、F2(文件监听实时流)、F3(启动 + 打断 + 建议)、F4(索引 + 恢复)、F5;
- F6 用量统计纳入(数据完整度按工具标注);
- **暂不做**:任务排队、远程访问、团队协作、统一凭据管理(只做只读展示)、自动路由(只做建议)。

### 非目标(Non-goals)
- ❌ 用 API 重新实现任何工具的能力;
- ❌ 云端服务/多用户/账号体系;
- ❌ 修改或迁移各工具的会话数据(只读);
- ❌ 替各工具做身份登录(复用其现有凭据与进程)。

## 5. 验收标准(v0.1)

1. 打开控制台,能看到 4 个工具的卡片与真实状态(本机实测);
2. 在控制台给任一工具发任务,能在页面看到实时消息流,能打断;
3. 每个工具的历史会话可浏览、可一键在原生工具中恢复;
4. 全程不破坏、不复制、不修改原工具的会话数据。
