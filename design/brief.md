# OpenHarness 前端设计任务:《阿衰》式彩色漫画风

## 背景
OpenHarness 是一个个人 AI Agent 控制台(Web 应用),统一管理 Cursor、Claude Code、Codex、DeepSeek Harness 四个 AI 编程工具:实时活动流、Agent 状态卡、发任务面板、会话索引、用量统计、配置页。功能已开发完成,现在需要**重新设计视觉风格**。

## 设计要求:彩色漫画风(参考《阿衰》漫画)
《阿衰》是猫小乐的校园搞笑漫画:高饱和明亮撞色、粗黑描边、手绘感、网点纸纹理、爆炸星形贴纸、Q 版幽默、大量白色漫画格。请把控制台设计成"一本活起来的彩色漫画书",但**必须保持工具的可读性与可用性**(这是开发者每天用的工具,不是纯装饰页)。

## 必须包含的区块(信息架构不变)
1. 顶部栏:标题「OPENHARNESS」漫画字标 + 星形徽章 + 连接状态 + 时钟 + 发任务按钮
2. 左侧:4 张 Agent 卡(Cursor / Claude Code / Codex / DeepSeek Harness)——每张卡是一个漫画格:Q 版角色头像 + 对话气泡显示状态(待命/运行中/未接入)+ 会话数/任务数 + "信号火花条"(原 LED 表的漫画化:事件进来点亮一个星形火花)
3. 主区:标签页(活动流/会话索引/用量/配置)+ 实时活动流(时间戳 + Agent + 事件类型徽章 + 消息内容,新事件滑入)
4. 发任务抽屉:Agent 选择、工作目录、任务描述、排队执行勾选、按特色匹配的建议卡
5. 用量页:统计卡、按工具/按天/按项目的条形图(漫画色)
6. 空状态:对话气泡 + 手绘小表情

## 必须输出的设计体系(写在文件末尾的 HTML 注释里,供工程师移植)
- 配色:4-6 个主色 hex(漫画撞色,含纸色、墨色)+ 每个 Agent 的专属识别色
- 字体:中文手绘感字体 + 英文漫画粗体 + 数据等宽字体(注明推荐字体名)
- 描边/圆角/阴影规范(粗黑描边 + 硬偏移阴影,无模糊)
- 网点纹理的做法(CSS radial-gradient 等)
- 每个组件的样式要点
